# WBPSC Miscellaneous Prelims Mock Tests

Two full 100-question mock tests (75 General Studies + 25 Arithmetic), 90-minute timer, +2 / -2/3 marking, instant green/red answer feedback.

## Files
- `index.html` menu page
- `test.html` test page
- `style.css` styles
- `app.js` test engine
- `data/mock1.js`, `data/mock2.js` questions (edit or add sets here)

## Publish on GitHub Pages
1. Create a repo and upload all files (keep the `data` folder).
2. Settings > Pages > Source: Deploy from branch > `main` / root > Save.
3. Share `https://<username>.github.io/<repo>/`
